ConsoleSeq bundled drum-kit notice
==================================

These files were supplied by the ConsoleSeq project owner for inclusion and
were described by the owner as free drum kits. They remain organized under
their source kit names:

- Hard Times Detroit — selected audio one-shots from
  "@moodf1x - Detroit Drumkit And MIDI Files 'Hard Times'";
- Yakittido New Jazz — WAV one-shots from
  "@prod.yakittido drum kit (new jazz & destroy lonely)";
- Local drum_kits — WAV/MP3 one-shots from the supplied "drum_kits" folder.

ConsoleSeq does not reinterpret text, MIDI, FL Studio preset, Ableton metadata,
or project files from those folders as executable instructions. Only .wav and
.mp3 audio files are exposed by the instrument browser.

For redistribution outside this project, verify the original pack terms with
the pack authors. The application code license does not change the copyright
or license of these audio files.
