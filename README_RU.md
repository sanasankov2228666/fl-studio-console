# ConsoleSeq — подробная инструкция на русском

ConsoleSeq — терминальный музыкальный секвенсор. Внутри уже есть готовые Kick, Snare, HiHat, Piano и Bass, поэтому для первого запуска не нужны внешние WAV-файлы. При старте загружается демонстрационный рок-бит: если аудиовыход работает, достаточно нажать `P`.

## Самое важное: почему при нажатии P может не быть звука

Смотрите на верхнюю строку интерфейса:

- `AUDIO` — звуковое устройство открыто, звук должен воспроизводиться.
- `SILENT` — транспорт и курсор работают, но аудиовыход не открыт. Нажатие `P` в этом режиме не даст звука.

На текущем компьютере проверено:

- нативный запуск из Windows открывает `WASAPI` и воспроизводит звук;
- в WSL обычной ALSA-карты нет, а сервер WSLg PulseAudio сейчас не отвечает на запрос устройств;
- поэтому для гарантированного звука запускайте ConsoleSeq из Windows PowerShell, а не из пути `/mnt/d/...` внутри WSL.

## Рекомендуемый запуск со звуком — Windows

Откройте Windows PowerShell и выполните:

```powershell
Set-Location 'D:\фигня\fl_studio'
.\setup.cmd
.\run.cmd
```

Первая команда сборки может выполняться несколько минут. Повторная сборка намного быстрее.

После запуска в верхней строке должно быть примерно следующее:

```text
ConsoleSeq | STOP | AUDIO | BPM 120.0 | PATTERN | Pat 1 Step 01 Slot 01
```

Если написано `AUDIO`, нажмите `P`. В демонстрационном паттерне уже включены шаги, поэтому сразу должен заиграть бит.

`setup.cmd` сам запускает PowerShell только для сборки с временным `ExecutionPolicy Bypass`; менять постоянную политику системы не требуется.

Не запускайте со следующей опцией, если нужен звук:

```powershell
.\run.cmd --no-audio
```

`--no-audio` специально отключает аудиоустройство и всегда показывает `SILENT`.

## Быстрый первый пример

1. Запустите `.\run.cmd` из Windows PowerShell или CMD.
2. Убедитесь, что наверху написано `AUDIO`.
3. Нажмите `P` — начнётся воспроизведение демонстрационного Pattern 1.
4. Нажмите `F2`, чтобы выбрать Snare.
5. Стрелками `Left`/`Right` переместитесь на нужный шаг.
6. Нажмите `Space`, чтобы включить или выключить удар Snare на этом шаге.
7. Изменение будет слышно на следующем проходе паттерна.
8. Нажмите `+` несколько раз, чтобы ускорить темп, или `-`, чтобы замедлить.
9. Нажмите `P` ещё раз — воспроизведение остановится и позиция вернётся в начало.
10. Нажмите `S`, введите `my_first_song.cseq` и нажмите `Enter`.

## Из чего состоит экран

### Верхняя строка

Показывает:

- `PLAY` или `STOP`;
- `AUDIO` или `SILENT`;
- текущий BPM;
- режим `PATTERN` или `SONG`;
- номер паттерна, шага и song-слота.

### Pattern

Главная сетка шагового секвенсора. Строки — инструменты, колонки — шаги.

- `X` — шаг активен и сыграет.
- `.` — шаг выключен.
- подсвеченная ячейка — текущий курсор.

При 16 шагах один паттерн соответствует одному такту из шестнадцатых нот.

### Channels

Список каналов:

1. Kick
2. Snare
3. HiHat
4. Piano
5. Bass

Рядом отображаются флаги `M` (mute) и `S` (solo).

### Song

Аранжировка из 16 слотов. В каждой ячейке хранится номер паттерна для конкретного канала. Благодаря отдельным строкам один и тот же song-слот может использовать разные паттерны на Kick, Snare, Piano и остальных каналах.

### Mixer

Показывает громкость, панораму, mute и solo каждого канала.

## Управление транспортом

| Клавиша | Действие |
|---|---|
| `P` | Начать воспроизведение. Если уже играет — остановить и вернуться в начало. После паузы — продолжить. |
| `A` | Пауза с сохранением позиции. |
| `T` | Включить или выключить повтор. |
| `+` / `-` | Увеличить или уменьшить BPM. Диапазон: 40–300. |
| `Q` | Выйти из приложения. |

Важно: `Space` не запускает транспорт. В Pattern он меняет шаг, а в Song — содержимое ячейки. Для запуска всегда используйте `P`.

## Как написать свой барабанный паттерн

### Вариант 1 — изменить готовый бит

После запуска выбран Pattern 1:

- Kick уже стоит на шагах 1, 5, 9 и 13;
- Snare — на шагах 5 и 13;
- HiHat — на каждом втором шаге.

Пример добавления дополнительного Kick:

1. Нажмите `F1`.
2. Стрелками перейдите на шаг 11.
3. Нажмите `Space`: вместо `.` появится `X`.
4. Нажмите `P`, если воспроизведение ещё не запущено.

Пример добавления Snare:

1. Нажмите `F2`.
2. Перейдите на шаг 9.
3. Нажмите `Space`.

Удаление шага: выберите его и нажмите `Backspace` или `Delete`.

### Вариант 2 — создать пустой паттерн

В проекте уже существуют Pattern 1–4; второй, третий и четвёртый пустые.

1. Нажмите `.` один раз, чтобы перейти с Pattern 1 на Pattern 2.
2. Нажмите `F1`, расставьте Kick клавишей `Space`.
3. Нажмите `F2`, расставьте Snare.
4. Нажмите `F3`, расставьте HiHat.
5. Для нового дополнительного паттерна нажмите `N`.

### Подробный пример: заполнить Pattern 2, 3 и 4

Pattern 2–4 уже созданы, поэтому `N` для них нажимать не нужно.

1. В режиме `PATTERN` нажмите `.` один раз — сверху появится `Pat 2`.
2. Сделайте второй бит: выберите Kick и включите шаги 1, 7, 9 и 15; выберите Snare и включите 5 и 13; выберите HiHat и включите нечётные шаги.
3. Нажмите `.` ещё раз — это Pattern 3. Например, оставьте только Kick на 1/9 и Snare на 5/13: получится спокойная часть.
4. Нажмите `.` ещё раз — это Pattern 4. Сделайте заполнение перед припевом: томы или snare можно поставить на 11, 13, 14, 15 и 16.
5. Для мгновенного перехода к нужному номеру нажмите `G`, введите `2`, `3` или `4` и нажмите `Enter`.
6. Чтобы переименовать текущий паттерн, нажмите `R` и введите, например, `Verse`, `Break` или `Fill`.

Как добавить Pattern 5 или любой следующий:

1. Нажмите `N`. Создастся новый пустой Pattern 5, и редактор сразу переключится на него.
2. Расставьте шаги инструментов клавишей `Space`.
3. Если нужен не пустой паттерн, а вариация текущего, вместо `N` нажмите `B`: текущий паттерн будет клонирован.
4. Нажмите `R`, чтобы дать новой части понятное имя.
5. В Song Mode назначайте Pattern 5 клавишей `5`. Для паттерна с номером больше 9 нажмите `G` и введите полный номер.

Переключение паттернов:

- `,` — предыдущий;
- `.` — следующий;
- `N` — создать новый пустой паттерн;
- `B` — клонировать текущий паттерн вместе со всеми нотами;
- `R` — переименовать текущий паттерн;
- `X` — удалить паттерн; ссылки на него в Song станут пустыми;
- `G` — перейти к паттерну по номеру;
- `D` — полностью очистить текущий паттерн после подтверждения;
- `C` — скопировать весь паттерн;
- `V` — вставить скопированный паттерн в текущий.

## Как добавить канал и выбрать другой инструмент

Нажмите `I` из любого основного экрана. Откроется библиотека из 22 пресетов. Выбирайте стрелками `Up`/`Down`, применяйте клавишей `Enter`, отменяйте через `Esc`.

Доступные группы:

- Kick: `Deep Kick`, `Punch Kick`, `808 Kick`;
- Snare/Clap: `Tight Snare`, `Big Snare`, `Hand Clap`;
- Hat/Percussion: `Closed Hat`, `Open Hat`, `Low Tom`, `High Tom`, `Perc Click`;
- Keys: `Bright Piano`, `Soft Piano`, `Electric Keys`;
- Bass: `Saw Bass`, `Square Bass`, `Sub Bass`, `Pluck Bass`;
- Synth: `Saw Lead`, `Square Lead`, `Warm Pad`, `Synth Pluck`.

После выбора создаётся новая строка Pattern, новая строка Song и новый канал Mixer. Все существующие паттерны автоматически расширяются. Максимум — 32 канала. Каналы ниже десятого выбираются стрелками; список автоматически прокручивается.

Чтобы изменить уже существующий канал, выберите его и нажмите `Enter`:

- `P` — заменить тембр другим встроенным пресетом;
- `H` — переименовать канал;
- `C` — клонировать канал вместе с его шагами во всех паттернах и назначениями Song;
- `X` — удалить канал после подтверждения;
- `W` — загрузить пользовательский WAV.

Пример добавления второго баса: нажмите `I`, стрелками найдите `[BASS] Sub Bass`, нажмите `Enter`, расставьте его шаги и при необходимости откройте настройки ещё одним `Enter`.

## Как пользоваться Piano и Bass

### Добавить ноту

1. В Pattern нажмите `F4` для Piano или `F5` для Bass.
2. Перейдите стрелками на нужный шаг.
3. Нажмите `Space`, чтобы включить ноту.
4. Клавишами `[` и `]` понижайте или повышайте MIDI-ноту выбранного шага.
5. Клавиши `{` и `}` меняют ноту сразу на октаву вниз/вверх.
6. `;` уменьшает velocity выбранного шага, а `'` увеличивает её с шагом 0.05.

Название ноты и MIDI-номер отображаются внизу Pattern-панели, например `C4 (60)`.

### Изменить синтезатор

На строке Piano или Bass нажмите `Enter`. Откроется меню инструмента:

- `O` — переключить генератор Sine → Square → Saw;
- `N` — установить базовую MIDI-ноту;
- `A` — Attack;
- `D` — Decay;
- `E` — Sustain;
- `R` — Release.
- `F` — Tone/частота фильтра, диапазон 0–1;
- `G` — Drive/насыщение, диапазон 0–1;
- `P` — выбрать другой пресет;
- `H` — переименовать, `C` — клонировать, `X` — удалить канал.

После выбора параметра введите число и нажмите `Enter`. Например, для более длинного хвоста Bass выберите `R` и введите `0.5`.

## Как собрать песню в Song Mode

1. Сначала создайте или заполните несколько паттернов.
2. Нажмите `Tab` один раз, чтобы перейти из Pattern в Song. В верхней строке появится `SONG`.
3. Стрелки `Up`/`Down` выбирают канал.
4. Стрелки `Left`/`Right` выбирают song-слот.
5. Нажмите цифру `1`–`9`, чтобы назначить соответствующий паттерн текущей ячейке.
6. `Space` или `Enter` циклически меняет номер паттерна.
   Для номера больше 9 нажмите `G`, введите номер и подтвердите `Enter`.
7. `Backspace`/`Delete` очищает ячейку.
8. Нажмите `P` для воспроизведения аранжировки.

Пример: использовать Pattern 2 в пятом слоте для всех каналов:

1. Перейдите в Song через `Tab`.
2. Стрелкой `Right` перейдите к слоту 5.
3. На строке Kick нажмите `2`.
4. Нажмите `Down`, затем `2` для Snare.
5. Повторите для HiHat, Piano и Bass.

Если текущий song-слот пуст на всех каналах, в Song Mode будет тишина, даже когда сверху написано `AUDIO`. Вернитесь в Pattern через `Tab` или назначьте паттерны в Song.

## Как пользоваться Mixer

Нажимайте `Tab`, пока фокус не перейдёт в `MIXER`.

| Клавиша | Действие |
|---|---|
| `Page Up` / `K` | Предыдущий канал. |
| `Page Down` / `J` | Следующий канал. |
| `Up` / `Down` | Увеличить / уменьшить громкость. |
| `Left` / `Right` | Панорама влево / вправо. |
| `M` | Mute выбранного канала. |
| `O` | Solo выбранного канала. |

Если включён Solo хотя бы на одном канале, слышны только solo-каналы. Если звук неожиданно пропал, проверьте буквы `M` и `S` в Channel/Mixer.

## Как загрузить свой WAV

1. Выберите канал клавишей `F1`–`F10` или стрелками `Up`/`Down` в Pattern.
2. Нажмите `W`.
3. Введите полный путь к WAV-файлу и нажмите `Enter`.

Рекомендуемый формат: PCM WAV, mono или stereo. Файл автоматически преобразуется в mono и ресемплируется до 44.1 kHz.

Пример Windows-пути:

```text
D:\Samples\kick.wav
```

Если WAV не открылся, старый встроенный звук остаётся активен. Путь к пользовательскому WAV сохраняется в проекте, но сам WAV внутрь `.cseq` не копируется.

## Сохранение и загрузка проекта

- `S` — сохранить;
- `L` — загрузить;
- расширение проекта — `.cseq`;
- файл является обычным JSON и хранит BPM, динамические каналы, выбранные пресеты, ADSR/Tone/Drive, Mixer, паттерны, velocity, ноты и Song.

Пример:

1. Нажмите `S`.
2. Введите `demo_song.cseq`.
3. Нажмите `Enter`.
4. Позже нажмите `L`, введите `demo_song.cseq` и нажмите `Enter`.

Можно открыть проект сразу при запуске:

```powershell
.\run.cmd .\demo_song.cseq
```

## Главное меню

Нажмите `Esc`:

- `N` — новый демонстрационный проект;
- `O` — открыть проект;
- `S` — сохранить;
- `I` — добавить инструмент/канал из библиотеки пресетов;
- `E` — открыть настройки выбранного канала;
- `W` — загрузить WAV;
- `Z` — переключить длину паттернов 16 → 32 → 64;
- `R` — закрыть меню;
- `Q` — выйти.

При уменьшении 64/32 шагов до меньшего размера данные после новой границы удаляются после подтверждения.

## Диагностика звука

### Проверка Windows

В PowerShell из папки проекта:

```powershell
.\.venv-win\Scripts\python.exe -c "from console_seq import Engine; e=Engine(); print(e.start()); print(e.audio_status()); e.shutdown()"
```

Рабочий результат на текущем компьютере:

```text
True
RtAudio output active (wasapi)
```

Если результат `False` или начинается с `silent timing mode`:

1. Проверьте, что в Windows выбран работающий динамик/наушники по умолчанию.
2. Закройте программы, которые могли открыть устройство в эксклюзивном режиме.
3. Проверьте ConsoleSeq в Windows Volume Mixer.
4. Перезапустите приложение без `--no-audio`.
5. Повторно выполните `setup.ps1`.

### Если наверху AUDIO, но музыки нет

Проверьте последовательно:

1. Вверху действительно `PLAY`, а не `STOP`.
2. Вы находитесь в Pattern с активными `X`, либо в непустом Song-слоте.
3. На каналах не установлен `M`.
4. Не включён Solo на другом канале.
5. Громкость Mixer не равна нулю.
6. Громкость Windows и физического устройства не равна нулю.

Быстрый сброс: нажмите `Esc`, затем `N`, подтвердите новый проект и нажмите `P`.

## Звук в WSL — необязательный режим

WSL не является рекомендуемым аудиохостом для этого проекта. Самый надёжный вариант — собирать код в WSL при необходимости, но запускать UI через Windows `run.cmd`.

Если всё же нужен звук через WSLg:

1. Сохраните работу и закройте приложения WSL.
2. В Windows PowerShell выполните:

```powershell
wsl --shutdown
```

Эта команда завершает все работающие процессы WSL.

3. Снова откройте WSL.
4. Проверьте сервер:

```bash
echo "$PULSE_SERVER"
ls -l /mnt/wslg/PulseServer
```

Обычно адрес выглядит как `unix:/mnt/wslg/PulseServer`.

5. Пересоберите и явно запросите PulseAudio:

```bash
cd /mnt/d/фигня/fl_studio
./setup.sh
CONSOLESEQ_AUDIO_API=pulse ./run.sh
```

Если запуск задерживается или сверху остаётся `SILENT`, WSLg PulseAudio на текущем сеансе неработоспособен. Нажмите `Q` и используйте Windows `run.cmd`.

## Проверка без интерфейса

Windows:

```powershell
.\run.cmd --smoke-test
```

WSL/Linux:

```bash
./run.sh --smoke-test
```

Smoke test проверяет движок, генерацию сигнала и save/load, но намеренно не проигрывает звук через динамики.

## Частые проблемы

### `No Python at '/usr/bin/python.exe'`

Используется старое смешанное окружение Windows/WSL. Запустите актуальный setup для своей системы:

- Windows: `setup.ps1` и `.venv-win`;
- WSL/Linux: `setup.sh` и `.venv-unix`.

### `PSSecurityException` / «выполнение сценариев отключено»

Не запускайте `.\run.ps1` напрямую. Используйте batch-launcher, который не блокируется PowerShell Execution Policy:

```powershell
.\setup.cmd
.\run.cmd
```

Если проект уже собран, можно вообще обойти все скрипты:

```powershell
.\.venv-win\Scripts\python.exe .\main.py
```

### `IndexError: Song channel or slot is out of range`

Это была ошибка отрисовки на широких терминалах. В текущей версии исправлена. Распакуйте новый архив или используйте обновлённые файлы проекта, затем снова запустите `setup.sh`.

### Интерфейс обрезан

Увеличьте окно терминала. Минимум — 76×20, удобный размер — от 100×28.

### Клавиши F1–F10 перехватываются терминалом

Выбирайте канал стрелками `Up`/`Down` в Pattern или настройте терминал так, чтобы функциональные клавиши передавались приложению.

## Рекомендуемый учебный сценарий

1. Запустите Windows-версию и добейтесь индикатора `AUDIO`.
2. Послушайте готовый Pattern 1.
3. Измените Kick и Snare через `Space`.
4. Перейдите на Pattern 2 клавишей `.` и создайте второй вариант бита.
5. Добавьте Piano/Bass, меняя ноты через `[`/`]`.
6. Перейдите в Song и расставьте Pattern 1/2 по слотам.
7. Отрегулируйте Mixer.
8. Сохраните проект через `S`.

Этого достаточно, чтобы собрать законченную циклическую композицию без внешних файлов.
