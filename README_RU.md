# ConsoleSeq 1.2 — подробная инструкция на русском

ConsoleSeq — клавиатурный музыкальный секвенсор с интерфейсом в терминале. Звуковой движок написан на C++17, интерфейс — на Python/curses. В проект входят 60 процедурно сгенерированных инструментов, паттерны, Song Mode, микшер, WAV/MP3, сохранение `.cseq` и автономный Windows EXE.

Все встроенные звуки создаются движком, поэтому они уже находятся внутри `ConsoleSeq.exe`: отдельный drum kit скачивать не требуется. Piano, Guitar и Strings — компактные физически/спектрально моделированные тембры, а не многогигабайтные multisample-библиотеки; это сохраняет автономность программы.

## Самый быстрый запуск на Windows

Готовая сборка:

```powershell
Set-Location 'D:\фигня\fl_studio'
.\ConsoleSeq.exe
```

Для запуска из исходников и пересборки:

```powershell
.\setup.cmd
.\run.cmd
```

`setup.cmd`, `run.cmd` и `build_exe.cmd` работают даже при запрещённом выполнении `.ps1`: они используют временный `ExecutionPolicy Bypass` только для своего процесса. Менять системную политику PowerShell не нужно.

После запуска посмотрите на верхнюю строку:

- `AUDIO` — устройство открыто, нажмите `P` и услышите готовый demo beat;
- `SILENT` — редактирование работает, но аудиоустройство не открыто;
- `PLAY`/`STOP` — состояние транспорта;
- `PATTERN`/`SONG` — текущий режим воспроизведения.

Не используйте `--no-audio`, если нужен звук. На Windows рекомендуется обычный Windows Terminal/PowerShell, а не WSL.

## Первый бит за пять минут

1. Запустите `ConsoleSeq.exe` и убедитесь, что сверху написано `AUDIO`.
2. Нажмите `P`: Pattern 1 уже содержит Kick, Snare, HiHat, Piano и Bass.
3. Нажмите `F2`, стрелками выберите шаг Snare и нажмите `Space` — шаг включится или выключится.
4. Нажмите `F4`, выберите активный шаг Piano, меняйте ноту клавишами `[` и `]`.
5. Нажмите `I`, стрелками `Left/Right` выберите категорию, `Up/Down` — звук, `Enter` — добавьте канал.
6. Нажмите `n`, чтобы создать один новый паттерн, или `N`, чтобы добавить сразу 16.
7. Нажмите `Tab`, расставьте паттерны в Song Mode.
8. Нажмите `Tab` ещё раз, настройте громкость и панораму в Mixer.
9. Нажмите `S`, введите `my_beat.cseq`, нажмите `Enter`.

Важно: `P` запускает/останавливает музыку. `Space` редактирует текущую ячейку и не управляет транспортом.

## Экран

- **Top Bar**: BPM, AUDIO/SILENT, PLAY/STOP, режим, текущие Pattern/Step/Slot.
- **Pattern**: строки каналов и 16/32/64 шага. `X` — активный шаг, `.` — пустой.
- **Channels**: список каналов и флаги `M` (mute), `S` (solo).
- **Song**: для каждого канала назначается паттерн на каждом слоте песни.
- **Mixer**: громкость, панорама, mute и solo.
- **Status**: подсказки и сообщения об ошибках.

Удобный размер терминала — 100×28 и больше, минимальный — 76×20.

## Библиотека инструментов

Нажмите `I`, чтобы добавить канал, либо выберите существующий канал, нажмите `Enter`, затем `P`, чтобы сменить его пресет.

В браузере:

- `Left`/`Right` или `Tab` — категории-вкладки;
- `Up`/`Down` — инструмент внутри категории;
- `Enter` — выбрать;
- `Esc`/`Q` — отменить.

Встроено 60 тембров в 10 категориях:

- **Pianos**: Classical Piano, Studio Grand, Bright/Soft Piano, Rhodes, Electric Keys;
- **Kicks**: Deep, Punch, 808, Trap Hard/Soft, Distorted, Detroit;
- **Basses**: Saw, Square, Sub, Pluck, 808 Clean Short/Long, 808 Distorted, Modern Rap Bass;
- **Guitars**: Acoustic, Electric Clean, Electric Drive;
- **Strings**: String Ensemble, Solo Strings;
- **Synths**: Saw/Square/Analog/FM Leads, FM Bell/Keys, Warm/Air Pads, Synth/New Jazz Plucks;
- **Snares**: Tight, Big, Trap, Detroit, Rimshot, Hand/Trap Clap;
- **Hi-hats**: Closed, Open, Trap Short, Metal, Hat Roll;
- **Percussion**: Low/High Tom, Click, New Jazz, Jerk, Detroit, Cowbell, Shaker;
- **FX**: Impact, Noise Riser, Reverse Cymbal, Vinyl Texture.

Максимум — 32 канала. Новый канал автоматически появляется во всех паттернах, Song и Mixer.

## Управление каналами

Выберите канал стрелками в Pattern либо `F1`–`F10`, затем нажмите `Enter`:

- `P` — открыть категории пресетов;
- `H` — переименовать;
- `C` — дублировать вместе с шагами и Song-назначениями;
- `X` — удалить после подтверждения;
- `W` — загрузить свой WAV/MP3;
- `O` — сменить Sine → Square → Saw → Triangle для синтезатора;
- `N` — базовая MIDI-нота;
- `A/D/E/R` — Attack/Decay/Sustain/Release;
- `F` — Tone/filter (0–1);
- `G` — Drive (0–1).

При удалении канала соответствующая строка корректно удаляется из каждого паттерна и каждого Song-слота. Последний канал удалить нельзя.

## Ноты и velocity

Для мелодического канала в Pattern:

- `Space` — включить/выключить ноту;
- `[` / `]` — полутон вниз/вверх;
- `{` / `}` — октава вниз/вверх;
- `;` / `'` — velocity −/+ 0.05.

Название ноты и MIDI-номер показываются внизу панели, например `C4 (60)`.

## Паттерны 1–512

Жёсткого ограничения в 16 больше нет:

- `n` — добавить один пустой паттерн;
- `N` — добавить банк из 16 паттернов;
- `Page Up`/`Page Down` — перейти между банками 1–16, 17–32, 33–48 и т.д.;
- `,` / `.` — предыдущий/следующий паттерн;
- `G` — перейти по полному номеру;
- `B` — дублировать текущий;
- `R` — переименовать;
- `X` — удалить с подтверждением;
- `C` / `V` — копировать/вставить весь паттерн;
- `D` — очистить паттерн;
- `Delete`/`Backspace` — очистить выбранный шаг.

При удалении паттерна следующие сдвигаются влево. Song-ссылки на удалённый паттерн очищаются, а ссылки на более высокие номера уменьшаются на один.

### Пример: создать Pattern 2, 3 и 4

Новый проект уже содержит четыре паттерна: первый — demo, остальные пустые.

1. В Pattern нажмите `.` — выбран Pattern 2.
2. На Kick поставьте шаги 1, 7, 9, 15; на Snare — 5 и 13; на HiHat — нечётные.
3. Нажмите `.`, заполните Pattern 3 как куплет.
4. Нажмите `.`, заполните Pattern 4 как fill.
5. Нажмите `R` и назовите их `Chorus`, `Verse`, `Fill`.
6. Для Pattern 5 нажмите `n`; для Pattern 17–32 сразу нажмите `N`.
7. Чтобы сделать вариацию, перейдите на исходник и нажмите `B` вместо создания пустого.

Длину всех паттернов 16 → 32 → 64 шага можно менять через `Esc`, затем `Z`. При уменьшении хвост удаляется только после подтверждения.

## Song Mode и произвольная длина песни

Нажмите `Tab`, чтобы перейти в Song:

- стрелки — канал и слот;
- `1`–`9` — назначить Pattern 1–9;
- `G` — назначить любой номер до 512;
- `Space`/`Enter` — циклически выбрать паттерн;
- `Delete`/`Backspace` — очистить ячейку;
- `Page Up`/`Page Down` — банк слотов ±16;
- `P` — воспроизводить аранжировку.

Длина песни настраивается от 1 до 512 слотов: `Esc` → `Y` → число → `Enter`. При уменьшении поздние слоты удаляются после подтверждения. Пользователь сам определяет длину композиции.

Пример аранжировки: назначьте Pattern 2 всем каналам в слотах 1–4, Pattern 3 в слотах 5–8, Pattern 4 в слоте 9. Поскольку Song хранит отдельную ячейку для каждого канала, можно оставить FX только в одном слоте или использовать разные паттерны одновременно.

## Mixer

Нажимайте `Tab`, пока активен Mixer:

- `Page Up`/`K`, `Page Down`/`J` — выбрать канал;
- `Up`/`Down` — громкость 0–100;
- `Left`/`Right` — панорама;
- `M` — mute;
- `O` — solo.

Если включён хотя бы один Solo, слышны только solo-каналы. Master limiter защищает выход от жёсткого цифрового клиппинга.

## Свои WAV и MP3

Поддерживаются PCM/float WAV (mono/stereo) и MP3. Звук преобразуется в mono и ресемплируется до 44.1 kHz.

Самый простой способ:

1. Создайте папку проекта, например `D:\Music\MyBeat\Samples`.
2. Скопируйте туда `kick.wav` или `vocal.mp3`.
3. В ConsoleSeq выберите канал либо добавьте новый drum-канал.
4. Нажмите `W`.
5. Введите полный путь, например `D:\Music\MyBeat\Samples\kick.wav`.
6. Нажмите `Enter`, поставьте шаг `Space` и запустите `P`.

Можно выбирать файл из любой папки; специальная папка установки не требуется. Если декодирование не удалось, старый встроенный звук остаётся активным и ошибка показывается в Status.

`.cseq` хранит путь к пользовательскому файлу, но не копирует сам WAV/MP3 внутрь. Для переноса проекта на другой компьютер переносите `.cseq` вместе с папкой `Samples` и сохраняйте ту же структуру/пути. Встроенные 60 инструментов всегда переносятся автоматически.

## Надёжное сохранение и загрузка

- `S` — сохранить;
- `L` — загрузить;
- формат — читаемый JSON с расширением `.cseq`;
- если указано только имя, файл создаётся в текущей папке запуска;
- полный сохранённый путь показывается в Status.

Пример:

1. Нажмите `S`.
2. Введите `D:\Music\MyBeat\song_v1.cseq`.
3. Нажмите `Enter`.
4. Для загрузки нажмите `L` и введите тот же путь.

Сохраняются BPM, loop/mode, все каналы и пресеты, WAV/MP3-пути, Mixer, ADSR/Tone/Drive, имена и размеры паттернов, ноты/velocity и вся Song-структура. Запись атомарная: сначала создаётся временный файл, затем он заменяет проект; незавершённый JSON не должен затереть предыдущую версию.

Проект можно открыть сразу:

```powershell
.\ConsoleSeq.exe 'D:\Music\MyBeat\song_v1.cseq'
```

## Все основные клавиши

| Клавиша | Действие |
|---|---|
| `P` / `A` / `T` | Play-Stop / Pause / Loop |
| `+` / `-` | BPM 40–300 |
| `Tab` | Pattern → Song → Mixer |
| Стрелки | Курсор; в Mixer громкость/панорама |
| `F1`–`F10` | Выбор канала |
| `I` / `Enter` | Добавить канал / настройки канала |
| `M` / `O` | Mute / Solo |
| `n` / `N` | +1 / +16 паттернов |
| `Page Up/Down` | Банк паттернов или Song-слотов ±16 |
| `B/R/X/G` | Duplicate / Rename / Delete / Go to pattern |
| `C/V/D` | Copy / Paste / Clear pattern |
| `S/L/W` | Save / Load / WAV-MP3 |
| `Esc` | Главное меню |
| `Q` | Выход |

## Сборка, тесты и EXE

Полная автоматическая сборка Windows:

```powershell
.\setup.cmd
```

Скрипт локально загружает недостающие Python 3.12, CMake, Ninja и w64devkit, собирает C++ зависимости, запускает native/Python/smoke‑тесты и создаёт:

```text
ConsoleSeq.exe
dist\ConsoleSeq.exe
```

Только пересобрать EXE:

```powershell
.\build_exe.cmd
```

Проверить EXE без интерфейса:

```powershell
.\ConsoleSeq.exe --smoke-test --no-audio --smoke-output .\check.cseq
```

Linux/macOS:

```bash
chmod +x setup.sh run.sh
./setup.sh
./run.sh
```

Готовый `.exe` предназначен для 64‑битной Windows 10/11. На Linux/macOS приложение запускается из исходников.

## Если нет звука

1. Уберите `--no-audio`.
2. Проверьте `AUDIO` и `PLAY` в верхней строке.
3. Убедитесь, что в Pattern есть `X`, либо Song-слот не пуст.
4. Проверьте Mute/Solo и громкость Mixer.
5. Проверьте устройство Windows по умолчанию и Volume Mixer.
6. Закройте программу, которая могла эксклюзивно занять устройство.
7. Запустите `Esc` → `N`, затем `P`.

Если наверху `SILENT`, попробуйте нативный Windows запуск `ConsoleSeq.exe` вместо WSL. Режим без звука всё равно позволяет редактировать, сохранять и проверять аранжировку.

## Частые проблемы

**PowerShell запрещает `.ps1`.** Используйте `.cmd`: `setup.cmd`, `run.cmd`, `build_exe.cmd`.

**Терминал перехватывает F-клавиши.** Выбирайте каналы стрелками `Up/Down` в Pattern.

**Интерфейс обрезан.** Увеличьте окно минимум до 76×20.

**Сэмпл пропал после переноса.** `.cseq` ссылается на внешний WAV/MP3; верните файл по сохранённому пути или загрузите его заново через `W`.

**Song молчит.** В Song Mode назначьте паттерны каждой нужной строке либо вернитесь в Pattern через `Tab`.

## Ограничения и roadmap

Сейчас отсутствуют запись с микрофона, VST, automation lanes, полноценный piano roll, эффекты по insert/send и экспорт WAV. Следующие логичные этапы: audio export, swing/groove, per-step probability, piano roll, эффекты, automation и MIDI input. Архитектура уже разделяет каталог пресетов, project state, renderer, Python binding и UI, а лимиты 512 паттернов/слотов и 32 канала защищают realtime‑движок от неконтролируемого роста.
