# ConsoleSeq 1.3.2 — подробная инструкция на русском

ConsoleSeq — клавиатурный музыкальный секвенсор с интерфейсом в терминале. Звуковой движок написан на C++17, интерфейс — на Python/curses. В версии 1.3.2 есть 100 пресетов, 167 встроенных WAV/MP3 one-shot из трёх драм-китов, FluidSynth с GeneralUser GS, изменение высоты любых сэмплов, цветные ноты с изменяемой длиной, контрастный курсор, непрозрачные всплывающие меню, Song Mode, микшер, portable EXE и Windows-установщик.

Старые лёгкие процедурные тембры сохранены. Новые категории `Live ...` играют сэмплированные тембры GeneralUser GS через FluidSynth: живое пианино, Родес, органы, акустические/электрогитары, басы, струнные, духовые и GM drum kits. SF2, DLL и все драм-киты включены в `ConsoleSeq.exe`; вручную скачивать их не нужно.

## Самый быстрый запуск на Windows

Есть два готовых варианта для другого пользователя Windows:

- `ConsoleSeq.exe` — portable-версия. Можно переслать один файл, дважды нажать на него и сразу работать. Python, FluidSynth, SF2, DLL и драм-киты уже внутри.
- `ConsoleSeq-Setup.exe` — установщик. Ставит программу в профиль пользователя, создаёт ярлыки, папку `Документы\ConsoleSeq Projects`, ассоциацию `.cseq` и запись в списке удаления Windows. Права администратора не нужны.

Запуск portable-сборки из терминала:

```powershell
Set-Location 'D:\фигня\fl_studio'
.\ConsoleSeq.exe
```

Для запуска из исходников и пересборки:

```powershell
.\setup.cmd
.\run.cmd
```

`setup.cmd`, `run.cmd` и `build_exe.cmd` работают даже при запрещённом выполнении `.ps1`: они используют временный `ExecutionPolicy Bypass` только для своего процесса. Менять системную политику PowerShell не нужно.

После запуска посмотрите на верхнюю строку:

- `AUDIO` — устройство открыто, нажмите `P` и услышите готовый demo beat;
- `SILENT` — редактирование работает, но аудиоустройство не открыто;
- `PLAY`/`STOP` — состояние транспорта;
- `PATTERN`/`SONG` — текущий режим воспроизведения.

Не используйте `--no-audio`, если нужен звук. На Windows рекомендуется обычный Windows Terminal/PowerShell, а не WSL.

## Первый бит за пять минут

1. Запустите `ConsoleSeq.exe` и убедитесь, что сверху написано `AUDIO`.
2. Нажмите `P`: Pattern 1 уже содержит Kick, Snare, HiHat, Piano и Bass.
3. Нажмите `F2`, стрелками выберите шаг Snare и нажмите `Space` — шаг включится или выключится.
4. Нажмите `F4`, выберите активный шаг Piano, меняйте ноту клавишами `[` и `]`.
5. Нажмите `I`, стрелками `Left/Right` выберите категорию (`Live Pianos` или `Kit: ...`), `Up/Down` — звук, `Enter` — добавьте канал.
6. Нажмите `n`, чтобы создать один новый паттерн, или `N`, чтобы добавить сразу 16.
7. Нажмите `Tab`, расставьте паттерны в Song Mode.
8. Нажмите `Tab` ещё раз, настройте громкость и панораму в Mixer.
9. Нажмите `S`, введите `my_beat.cseq`, нажмите `Enter`.

Важно: `P` запускает/останавливает музыку. `Space` редактирует текущую ячейку и не управляет транспортом.

## Готовый new jazz бит

В корне проекта находится `new_jazz.cseq`: аранжировка на 24 такта при 130 BPM с интро, двумя основными грувами, fill, breakdown, drop и outro. В ней используются Yakittido New Jazz и Hard Times one-shot’ы, питченная 808, Live Rhodes, pluck, FM bell, jazz guitar и pad.

Чтобы открыть бит, нажмите `L`, введите `new_jazz.cseq` и нажмите `Enter`. Проект загружается сразу в Song Mode; нажмите `P` для воспроизведения всей аранжировки. Для запуска напрямую:

```powershell
.\ConsoleSeq.exe .\new_jazz.cseq
```

Исходный генератор находится в `scripts\create_new_jazz.py`. Повторное создание проекта из исходников:

```powershell
.\.venv-win\Scripts\python.exe .\scripts\create_new_jazz.py .\new_jazz.cseq
```

## Экран

- **Top Bar**: BPM, AUDIO/SILENT, PLAY/STOP, режим, текущие Pattern/Step/Slot.
- **Pattern**: строки каналов и 16/32/64 шага. `X` — начало ноты/one-shot, `=` — её продолжение, `.` — пустой шаг. Каждый канал имеет свой цвет.
- **Channels**: список каналов и флаги `M` (mute), `S` (solo).
- **Song**: для каждого канала назначается паттерн на каждом слоте песни.
- **Mixer**: громкость, панорама, mute и solo.
- **Status**: подсказки и сообщения об ошибках.

Удобный размер терминала — 100×28 и больше, минимальный — 76×20.

Максимум — 32 канала. Новый канал автоматически появляется во всех паттернах, Song и Mixer.

## Управление каналами

Выберите канал стрелками в Pattern либо `F1`–`F10`, затем нажмите `Enter`:

- `P` — открыть категории пресетов;
- `H` — переименовать;
- `C` — дублировать вместе с шагами и Song-назначениями;
- `X` — удалить после подтверждения;
- `W` — загрузить свой WAV/MP3;
- `O` — сменить Sine → Square → Saw → Triangle для синтезатора;
- `N` — базовая MIDI-нота;
- `A/D/E/R` — Attack/Decay/Sustain/Release;
- `F` — Tone/filter (0–1);
- `G` — Drive (0–1).

При удалении канала соответствующая строка корректно удаляется из каждого паттерна и каждого Song-слота. Последний канал удалить нельзя.

## Ноты, velocity и длина

Для любого канала в Pattern, включая загруженный через `W` WAV/MP3 и one-shot из встроенного драм-кита:

- `Space` — включить/выключить ноту;
- `E` на `X` или любом `=` — войти в режим длины этой ноты;
- `Left`/`Right` в режиме длины — сократить/растянуть;
- `E` или `Esc` — выйти из режима длительности;
- `[` / `]` — полутон вниз/вверх;
- `{` / `}` — октава вниз/вверх;
- `;` / `'` — velocity −/+ 0.05.

По умолчанию один `X` имеет режим `one-shot`: WAV/MP3 доигрывает до конца. После `E` длина становится явной: `X  =  =  =`. Когда заданный хвост заканчивается, движок обрезает даже более длинный сэмпл. Растяжение не может перекрыть следующий `X`. `Backspace` на любом `=` удаляет всю ноту.

Название ноты, MIDI-номер, velocity и `one-shot`/`gate N steps` показываются внизу панели. Для сэмпла там также написано `original`, `+N st` или `-N st`: это отклонение от исходной высоты.

### Изменение высоты WAV/MP3 и kit-сэмплов

1. Загрузите файл через `W` или добавьте one-shot из вкладки `Kit: ...`.
2. Поставьте `X` клавишей `Space`.
3. Наведите курсор на его `X` либо на любой принадлежащий ему `=`.
4. Нажимайте `[` и `]`, чтобы опускать/поднимать именно этот шаг по одному полутону.
5. Нажимайте `{` и `}` (`Shift` + `[`/`]`), чтобы менять высоту сразу на октаву.

У каждого `X` может быть своя высота. Корневая нота канала означает исходное звучание файла без транспонирования. Например, `original` → `]` даст `+1 st`, а `}` — `+12 st`. Высота сохраняется в `.cseq` и копируется вместе с паттерном.

Транспонирование сэмпла работает классическим способом: при повышении он играет быстрее и становится короче, при понижении — медленнее и длиннее. Это не time-stretch с сохранением темпа. Явная длина `X ===`, заданная через `E`, всё равно обрезает голос на выбранной границе; обычный `X` остаётся one-shot и доигрывает естественную длину уже транспонированного файла.

### Пошаговый пример удлинения

1. Перейдите в Pattern клавишей `Tab`.
2. Стрелками `Up`/`Down` выберите Piano, Bass, WAV/MP3 или другой канал.
3. Стрелками `Left`/`Right` поставьте курсор на нужный шаг. Курсор имеет контрастный светлый фон и виден на `X`, `=` и `.`.
4. Если ячейка пустая, нажмите `Space`: появится `X`.
5. Нажмите `E`. Нота выделится, а в Status появится `Length edit`.
6. Каждое нажатие `Right` добавляет один `=`. `Left` убирает один `=`.
7. Нажмите `E` или `Esc`, чтобы закончить. Получится, например: `X = = = . . X =`.

Курсор можно поставить на любой `=` уже растянутой ноты и снова нажать `E`: движок сам найдёт её начало `X`. Минимум — один шаг; максимум — до конца паттерна или до следующего `X`. На 120 BPM один шаг равен 0,125 секунды; при другом BPM время меняется автоматически.

Если нажать `Space` внутри хвоста `=`, предыдущая нота сократится до этого места, а в текущей ячейке появится новый `X`. Длина нот копируется через `C`/`V` и сохраняется в `.cseq`.

## Паттерны 1–512

Жёсткого ограничения в 16 больше нет:

- `n` — добавить один пустой паттерн;
- `N` — добавить банк из 16 паттернов;
- `Page Up`/`Page Down` — перейти между банками 1–16, 17–32, 33–48 и т.д.;
- `,` / `.` — предыдущий/следующий паттерн;
- `G` — перейти по полному номеру;
- `B` — дублировать текущий;
- `R` — переименовать;
- `X` — удалить с подтверждением;
- `C` / `V` — копировать/вставить весь паттерн;
- `D` — очистить паттерн;
- `Delete`/`Backspace` — очистить выбранный шаг.

При удалении паттерна следующие сдвигаются влево. Song-ссылки на удалённый паттерн очищаются, а ссылки на более высокие номера уменьшаются на один.

### Пример: создать Pattern 2, 3 и 4

Новый проект уже содержит четыре паттерна: первый — demo, остальные пустые.

1. В Pattern нажмите `.` — выбран Pattern 2.
2. На Kick поставьте шаги 1, 7, 9, 15; на Snare — 5 и 13; на HiHat — нечётные.
3. Нажмите `.`, заполните Pattern 3 как куплет.
4. Нажмите `.`, заполните Pattern 4 как fill.
5. Нажмите `R` и назовите их `Chorus`, `Verse`, `Fill`.
6. Для Pattern 5 нажмите `n`; для Pattern 17–32 сразу нажмите `N`.
7. Чтобы сделать вариацию, перейдите на исходник и нажмите `B` вместо создания пустого.

Длину всех паттернов 16 → 32 → 64 шага можно менять через `Esc`, затем `Z`. При уменьшении хвост удаляется только после подтверждения.

## Song Mode и произвольная длина песни

Нажмите `Tab`, чтобы перейти в Song:

- стрелки — канал и слот;
- `1`–`9` — назначить Pattern 1–9;
- `G` — назначить любой номер до 512;
- `Space`/`Enter` — циклически выбрать паттерн;
- `Delete`/`Backspace` — очистить ячейку;
- `Page Up`/`Page Down` — банк слотов ±16;
- `P` — воспроизводить аранжировку.

Длина песни настраивается от 1 до 512 слотов: `Esc` → `Y` → число → `Enter`. При уменьшении поздние слоты удаляются после подтверждения. Пользователь сам определяет длину композиции.

Пример аранжировки: назначьте Pattern 2 всем каналам в слотах 1–4, Pattern 3 в слотах 5–8, Pattern 4 в слоте 9. Поскольку Song хранит отдельную ячейку для каждого канала, можно оставить FX только в одном слоте или использовать разные паттерны одновременно.

## Mixer

Нажимайте `Tab`, пока активен Mixer:

- `Page Up`/`K`, `Page Down`/`J` — выбрать канал;
- `Up`/`Down` — громкость 0–100;
- `Left`/`Right` — панорама;
- `M` — mute;
- `O` — solo.

Если включён хотя бы один Solo, слышны только solo-каналы. Master limiter защищает выход от жёсткого цифрового клиппинга.

## Свои WAV и MP3

Поддерживаются PCM/float WAV (mono/stereo) и MP3. Звук преобразуется в mono и ресемплируется до 44.1 kHz.

Самый простой способ:

1. Создайте папку проекта, например `D:\Music\MyBeat\Samples`.
2. Скопируйте туда `kick.wav` или `vocal.mp3`.
3. В ConsoleSeq выберите канал либо добавьте новый drum-канал.
4. Нажмите `W`.
5. Введите полный путь, например `D:\Music\MyBeat\Samples\kick.wav`.
6. Нажмите `Enter`, поставьте шаг `Space` и запустите `P`.
7. На выбранном `X` меняйте высоту клавишами `[`/`]` (полутон) либо `{`/`}` (октава).

Можно выбирать файл из любой папки; специальная папка установки не требуется. Если декодирование не удалось, старый встроенный звук остаётся активным и ошибка показывается в Status.

`.cseq` хранит путь к внешнему пользовательскому файлу, но не копирует сам WAV/MP3 внутрь. Для переноса проекта переносите `.cseq` вместе с папкой `Samples` и сохраняйте ту же структуру/пути. Встроенные пресеты, SF2 и 167 kit-сэмплов переносятся автоматически.

## Надёжное сохранение и загрузка

- `S` — сохранить;
- `L` — загрузить;
- формат — читаемый JSON с расширением `.cseq`;
- если указано только имя, файл создаётся в текущей папке запуска;
- полный сохранённый путь показывается в Status.

Пример:

1. Нажмите `S`.
2. Введите `D:\Music\MyBeat\song_v1.cseq`.
3. Нажмите `Enter`.
4. Для загрузки нажмите `L` и введите тот же путь.

Сохраняются BPM, loop/mode, все каналы и пресеты, FluidSynth bank/program, WAV/MP3/`asset://`-пути, Mixer, ADSR/Tone/Drive, имена и размеры паттернов, высота/velocity/длительность каждого шага и вся Song-структура. Запись атомарная: сначала создаётся временный файл, затем он заменяет проект. Формат проекта версии 5 автоматически переносит старые барабанные ноты из проектов версии 4 так, чтобы их прежняя высота не менялась.

Диалог имени файла теперь читает Unicode-символы через curses `get_wch`, поэтому пути вида `D:\фигня\мой бит.cseq` больше не превращаются в `￿￿￿`. Первый введённый символ заменяет предложенное имя; `Ctrl+U` очищает строку.

Проект можно открыть сразу:

```powershell
.\ConsoleSeq.exe 'D:\Music\MyBeat\song_v1.cseq'
```

## Сборка, тесты и EXE

Полная автоматическая сборка Windows:

```powershell
.\setup.cmd
```

Скрипт локально загружает недостающие Python 3.12, CMake, Ninja, w64devkit, официальный FluidSynth 2.6.0 SDK/runtime и GeneralUser GS, собирает C++ зависимости, запускает native/Python/smoke‑тесты и создаёт:

```text
ConsoleSeq.exe
dist\ConsoleSeq.exe
ConsoleSeq-Setup.exe
dist-installer\ConsoleSeq-Setup.exe
```

Только пересобрать EXE:

```powershell
.\build_exe.cmd
```

Пересобрать Windows-установщик (скрипт автоматически установит Inno Setup через `winget`, если его нет):

```powershell
.\build_installer.cmd
```

Собрать чистый архив с исходниками, звуками и готовым EXE:

```powershell
.\package_release.cmd
```

Проверить EXE без интерфейса:

```powershell
.\ConsoleSeq.exe --smoke-test --no-audio --smoke-output .\check.cseq
```

Linux/macOS:

```bash
chmod +x setup.sh run.sh
./setup.sh
./run.sh
```

Готовый `.exe` предназначен для 64‑битной Windows 10/11. На Linux/macOS приложение запускается из исходников.

Размер EXE значительно выше прежнего: внутри упакованы SF2 и около 91 МБ драм-китов. Лицензии GeneralUser GS и FluidSynth лежат в `assets\soundfonts` и `assets\licenses`; примечание о приложенных kit-файлах — в `assets\drum_kits\README.txt`.

## Если нет звука

1. Уберите `--no-audio`.
2. Проверьте `AUDIO` и `PLAY` в верхней строке.
3. Убедитесь, что в Pattern есть `X`, либо Song-слот не пуст.
4. Проверьте Mute/Solo и громкость Mixer.
5. Проверьте устройство Windows по умолчанию и Volume Mixer.
6. Закройте программу, которая могла эксклюзивно занять устройство.
7. Запустите `Esc` → `N`, затем `P`.

Если наверху `SILENT`, попробуйте нативный Windows запуск `ConsoleSeq.exe` вместо WSL. Режим без звука всё равно позволяет редактировать, сохранять и проверять аранжировку.

## Частые проблемы

**PowerShell запрещает `.ps1`.** Используйте `.cmd`: `setup.cmd`, `run.cmd`, `build_exe.cmd`, `build_installer.cmd`.

**Windows SmartScreen предупреждает о неизвестном издателе.** Это ожидаемо для нового EXE без платной code-signing подписи. Проверьте SHA-256 с автором, затем выберите «Подробнее» → «Выполнить в любом случае». Для публичного распространения лучше позже подписать оба файла сертификатом Authenticode.

**Терминал перехватывает F-клавиши.** Выбирайте каналы стрелками `Up/Down` в Pattern.

**Интерфейс обрезан.** Увеличьте окно минимум до 76×20.

**Сэмпл пропал после переноса.** `.cseq` ссылается на внешний WAV/MP3; верните файл по сохранённому пути или загрузите его заново через `W`.

**Song молчит.** В Song Mode назначьте паттерны каждой нужной строке либо вернитесь в Pattern через `Tab`.

**Live-инструмент молчит.** Запустите `ConsoleSeq.exe --smoke-test --no-audio`. Тест отдельно проверит DLL FluidSynth, SF2, WAV и MP3. В сборке из исходников повторите `setup.cmd`, если `assets\soundfonts\GeneralUser-GS.sf2` отсутствует.

## Ограничения и roadmap

Сейчас отсутствуют запись с микрофона, VST, automation lanes, полноценный piano roll, эффекты по insert/send и экспорт WAV.
